# fluent365-audio

Audiobooks for the Fluent365 reading ladder, read by Microsoft Edge neural voices (narrator en-US-Ava; dialogue in character voices).
Served by GitHub Pages next to the Fluent365 app, which opens `../fluent365-audio/index.json` by a relative path.

- One folder per book; per chapter an Opus/WebM file (24 kbit/s mono) and a JSON with the start time of every sentence and word.
- Generated by `scripts/gen-book-audio.py` in the Fluent365 repo. This repo is rebuilt as a single commit without history (force-pushed on regeneration).
- Book text: public domain (Project Gutenberg). Audio: generated with the Edge read-aloud service, which has no published licence for redistribution; see `docs/CONTENT_LICENSING.md` in the Fluent365 repo.
